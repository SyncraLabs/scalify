ScalifyLabs es una agencia de marketing digital con sede en España (operaciones en Canarias, Barcelona y Madrid). Nombre: ScalifyLabs

Propuesta de valor: No somos un proveedor más. Somos tu aliado estratégico digital. Estrategia + ejecución + resultados medibles.

4. Tono y Voz de Marca

Aspecto
Directriz
Tono general
Profesional pero cercano. Sin formalismos excesivos. Como hablar con un socio de confianza.
Enfoque de venta
Pain-first. Empieza por el problema del cliente, luego presenta la solución.
Lenguaje
Directo, sin rodeos. Evitar tecnicismos innecesarios. Vocabulario orientado a resultados.
Personalidad
Seguro, resolutivo, transparente. No arrogante. Datos > opiniones.
CTAs
Siempre orientados a acción: «Hablemos», «Empecemos», «Descubre cómo». Evitar «Saber más» genéricos.
Evitar
Superlativos vacíos («somos los mejores»), promesas no respaldadas, lenguaje corporativo frío.


Palabras clave de marca: escalar, crecer, resultados, estrategia, impacto, conversión, aliado, digitalizar, automatizar, facturación.


5. Paleta Visual y Diseño

Colores (basados en la marca actual)
Primario: #6C3AED (Púrpura vibrante) — Elemento principal de marca, CTAs, acentos.
Secundario: #3B82F6 (Azul eléctrico) — Links, hovers, elementos interactivos.
Oscuro: #0D0D0D — Textos principales, fondos hero.
Gris: #6B7280 — Textos secundarios, párrafos.
Fondo claro: #F9FAFB o #F3F0FF (lavanda muy suave) — Secciones alternas.
Blanco: #FFFFFF — Fondo principal.

Tipografía sugerida
Headlines: Poppins / Inter / Space Grotesk (bold, semi-bold)
Body: Inter / DM Sans (regular, medium)
Monospace (opcional): JetBrains Mono para secciones técnicas

Estilo visual
Minimalista moderno con toques de glassmorphism o gradientes suaves
Micro-animaciones: hover en tarjetas, scroll reveal, contadores animados
Iconos: Lucide o Phosphor (línea, coherentes)
Ilustraciones: 3D abstractas o isometric tech (evitar stock genérico)
Dark mode: considerar como feature premium
Fondo del hero: gradiente oscuro (negro a púrpura profundo) con partículas o mesh gradient


6. Funcionalidades Técnicas

Stack recomendado
Framework: Next.js 14+ (App Router) o Astro si se prioriza velocidad estática
Estilos: Tailwind CSS + shadcn/ui
Animaciones: Framer Motion
Formularios: React Hook Form + validación server-side
CMS (opcional): Sanity / Strapi / Markdown para blog y casos
Deploy: Vercel
Analytics: Vercel Analytics + Google Analytics 4

Features clave
Responsive design (mobile-first)
Velocidad: Core Web Vitals en verde (LCP < 2.5s, CLS < 0.1)
SEO técnico: meta tags dinámicos, Open Graph, sitemap, robots.txt, JSON-LD
Formulario de contacto con notificación por email (Resend / Nodemailer)
WhatsApp floating button
Scroll animations (fade-in, slide-up en secciónes)
Lazy loading de imágenes con blur placeholder
Página 404 personalizada
Cookie consent RGPD compliant
Multi-idioma (ES como principal, EN opcional)

9. Notas para Desarrollo (Claude Code)

Este documento es la fuente de verdad para copies y estructura. Usarlo como contexto al generar componentes.
Priorizar mobile-first. El 70%+ del tráfico será móvil.
Cada página de servicio sigue el mismo layout: Hero + Problema + Solución + Proceso + Resultados + CTA.
Componentes reutilizables: ServiceHero, TestimonialSlider, StatsCounter, CTASection, ServiceCard, CaseStudyCard.
Usar variables CSS / Tailwind config para los colores de marca definidos en la sección 5.
Implementar schema markup (JSON-LD) para Organization, LocalBusiness, y Service.
Las imágenes del portfolio y logos de clientes se añadirán después. Usar placeholders coherentes.
Formulario de contacto: integración con email (Resend API) + opcionalmente CRM.
La web actual tiene un typo en el footer: «SacalifyLabs» en vez de «ScalifyLabs». Corregir.
